┌────────────────────────────────────────────────────────────────────────────┐
│ ROOT CAUSE                                                                 │
└────────────────────────────────────────────────────────────────────────────┘

Firebase Storage has NO security rules configured.

By default, Firebase Storage DENIES ALL ACCESS when no rules are set.

This is why authenticated users cannot upload resumes.


┌────────────────────────────────────────────────────────────────────────────┐
│ SOLUTION                                                                   │
└────────────────────────────────────────────────────────────────────────────┘

Deploy Firebase Storage security rules.

A new file has been created: storage.rules

This file contains the security rules needed for:
  ✅ Authenticated users to upload resumes
  ✅ Admins to manage all uploads
  ✅ Public assets to be accessible


┌────────────────────────────────────────────────────────────────────────────┐
│ QUICK FIX (2 STEPS)                                                        │
└────────────────────────────────────────────────────────────────────────────┘

OPTION A: Using Firebase CLI (Recommended)

Step 1: Install Firebase CLI (if not already installed)
  npm install -g firebase-tools

Step 2: Deploy the storage rules
  firebase deploy --only storage

Done! Rules are now deployed.


OPTION B: Using Firebase Console

Step 1: Go to Firebase Console
  https://console.firebase.google.com/

Step 2: Select project: aaraa-infra-web

Step 3: Navigate to Storage → Rules

Step 4: Replace existing rules with content from storage.rules

Step 5: Click "Publish"

Done! Rules are now deployed.


┌────────────────────────────────────────────────────────────────────────────┐
│ WHAT THE RULES DO                                                          │
└────────────────────────────────────────────────────────────────────────────┘

Career Applications Upload:
  Path: career_applications/{leadId}/{fileName}
  
  Permissions:
    ✅ Authenticated users can UPLOAD resumes (max 10MB)
    ✅ Authenticated users can READ their own files
    ✅ Admins can READ/DELETE all applications
    ❌ Unauthenticated users CANNOT access

General Uploads:
  Path: uploads/{userId}/{fileName}
  
  Permissions:
    ✅ Authenticated users can upload to their own folder (max 50MB)
    ✅ Admins can manage all uploads
    ❌ Users cannot access other users' files

Public Assets:
  Path: public/{fileName}
  
  Permissions:
    ✅ Anyone can READ public assets (images, videos)
    ✅ Admins can UPLOAD/MANAGE public assets


┌────────────────────────────────────────────────────────────────────────────┐
│ SECURITY FEATURES                                                          │
└────────────────────────────────────────────────────────────────────────────┘

✅ Authentication Required
   - Only authenticated users can upload
   - Email must be verified via Google

✅ File Size Limits
   - Career applications: Max 10MB
   - General uploads: Max 50MB

✅ Admin Access
   - Admins (@aaraainfrastructure.com) can manage all files
   - Admins can delete applications

✅ User Isolation
   - Users can only upload to their own folder
   - Users cannot access other users' files

Still Getting Permission Error?

1. Clear browser cache
   - Press Ctrl+Shift+Delete
   - Clear all cache
   - Reload page

2. Verify authentication
   - Open console (F12)
   - Run: window.firebaseServices.auth.currentUser
   - Should return user object with email

3. Check rules deployment
   - Go to Firebase Console
   - Storage → Rules
   - Verify rules are published
   - Check "Last published" timestamp

4. Verify email is verified
   - In console, run: window.firebaseServices.auth.currentUser.emailVerified
   - Should return true

Rules Not Deploying?

1. Check Firebase CLI version
   firebase --version

2. Verify project ID
   firebase projects:list

3. Check firebase.json
   cat firebase.json

4. Try verbose deployment
   firebase deploy --only storage --debug
