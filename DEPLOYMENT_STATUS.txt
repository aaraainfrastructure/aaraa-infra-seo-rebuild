┌────────────────────────────────────────────────────────────────────────────┐
│ WHAT THE RULES DO                                                          │
└────────────────────────────────────────────────────────────────────────────┘

Career Applications:
  Path: career_applications/{leadId}/{fileName}
  
  ✅ Authenticated users can UPLOAD resumes (max 10MB)
  ✅ Authenticated users can READ their own files
  ✅ Admins can READ/DELETE all applications
  ❌ Unauthenticated users CANNOT access

General Uploads:
  Path: uploads/{userId}/{fileName}
  
  ✅ Authenticated users can upload to their own folder (max 50MB)
  ✅ Admins can manage all uploads
  ❌ Users cannot access other users' files

Public Assets:
  Path: public/{fileName}
  
  ✅ Anyone can READ public assets
  ✅ Admins can UPLOAD/MANAGE public assets

Still Getting Permission Error?

1. Clear browser cache
   Ctrl+Shift+Delete → Clear all → Reload

2. Verify rules deployed
   Firebase Console → Storage → Rules
   Check "Last published" timestamp

3. Verify authentication
   Open console (F12)
   Run: window.firebaseServices.auth.currentUser
   Should return user object

4. Try incognito mode
   Open career.html in incognito window
   Test upload again
