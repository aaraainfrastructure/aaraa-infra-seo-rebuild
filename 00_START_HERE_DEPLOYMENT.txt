════════════════════════════════════════════════════════════════════════════
                           HOW IT WORKS NOW
════════════════════════════════════════════════════════════════════════════

Old Process (Before):
   User fills form → Form submits to itself → HTTP 405 error → Firebase fallback

New Process (After):
   User fills form → API Bridge normalizes fields → Submits to /api/submit backend
   Backend successful? → Show success, save to Firestore → Done
   Backend failed? → Fall back to Firebase automatically → Done
   
Result: Faster, more reliable, better user experience

════════════════════════════════════════════════════════════════════════════
                          QUICK DEBUGGING
════════════════════════════════════════════════════════════════════════════

If something doesn't work:

ERROR: "Cannot read property 'preprocess' of undefined"
FIX: Script tag not loaded. Verify:
   - <script src="js/api-bridge.js"></script> exists in HTML
   - Script is BEFORE app.js
   - Hard refresh page (Ctrl+Shift+R)

ERROR: "HTTP 405 - Method Not Allowed"
FIX: Form not using API Bridge. Verify:
   - app.js has the updated handleFormSubmit() function
   - js/api-bridge.js exists
   - Script tag in HTML

ERROR: Form submits but no email
FIX: Backend might be down. Check:
   - Server running? (npm start)
   - SMTP configured in .env?
   - Check server logs for errors

ERROR: Fields missing from email
FIX: API Bridge should normalize automatically. Verify:
   - Form field names are standard (name, email, phone, message)
   - If different names, check field mapping in api-bridge.js
