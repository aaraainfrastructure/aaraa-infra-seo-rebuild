RECOMMENDATION: ✅ Use OPTION B (Lightweight)
Why? Smaller upload, fresh packages, same result

════════════════════════════════════════════════════════════════════════════
                       TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problem: "Port 3001 already in use"
Solution:
  • Change PORT in .env to 3002
  • Or kill process using port 3001
  • Restart server

Problem: "SMTP Auth Error"
Solution:
  • Verify .env has correct email/password
  • Check Gmail app password (not main password)
  • Get new app password: https://myaccount.google.com/apppasswords

Problem: "npm command not found"
Solution:
  • Install Node.js from nodejs.org
  • Restart terminal
  • Try again

Problem: "Files not copied"
Solution:
  • Verify destination folder exists
  • Check write permissions
  • Use full file paths
