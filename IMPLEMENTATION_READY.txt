================================================================================
                        FIELD MAPPING REFERENCE
================================================================================

NAME FIELD VARIATIONS:
   name, fullname, full_name, full-name, clientName, signatoryName
   → All normalize to: "name"

EMAIL FIELD VARIATIONS:
   email, mail, email_address, emailAddress, clientEmail, sender_email
   → All normalize to: "email"

PHONE FIELD VARIATIONS:
   phone, mobile, telephone, tel, phone_number, phoneNumber, clientPhone
   → All normalize to: "phone"

MESSAGE FIELD VARIATIONS:
   message, description, requirement, comment, notes, inquiry, enquiry
   → All normalize to: "message"

LEAD TYPE VARIATIONS:
   leadType, lead_type, reason, category, service, project_type, inquiry_type
   → All normalize to: "leadType"

AUTOMATIC LEAD TYPE VALUES:
   vendor form          → "Vendor Inquiry"
   subcontractor form   → "Subcontractor Inquiry"
   partnership form     → "Partnership Inquiry"
   career form          → "Career Inquiry"
   callback form        → "Callback Request"
   newsletter form      → "Newsletter Subscription"
   quick inquiry form   → "Quick Inquiry"
   contact/enquiry      → "Project Enquiry"
   (default/fallback)   → "General Inquiry"

                        TROUBLESHOOTING
================================================================================

ISSUE: HTTP 405 still appearing
   FIX: Check app.js has new handleFormSubmit function
       Verify script tags are in correct order
       Restart server: npm start

ISSUE: Form submitting but no email received
   FIX: Check .env has SMTP credentials
       Run: npm start and look for "SMTP Auth Success"
       Verify RECIPIENT_EMAIL is set

ISSUE: "API Bridge not found" in console
   FIX: Verify script tag: <script src="js/api-bridge.js"></script>
       Check script is in <head> before app.js
       Reload page

ISSUE: Fields missing from email
   FIX: Check form has all required fields
       Verify field names match (or API Bridge will normalize)
       Check leadType is set or auto-mapped

ISSUE: Cannot POST /api/submit
   FIX: Verify backend running: cd server && npm start
       Check server logs for errors
       Verify /api/submit route exists in server.js
