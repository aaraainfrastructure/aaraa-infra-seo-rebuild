Frequently Asked Questions

To prevent automated spam, malware, and DDoS attempts on our Google Cloud Storage folders, we require basic authentication using verified Google Sign-In. This is purely for file upload permissions and ensures a safe empanelment flow.

Resumes, Bonafide certificates, and GST/PAN certificates are limited to 10MB per file and must be in PDF or image format (JPEG/PNG). Larger files like capability statements or work order folders can be up to 15MB-20MB and uploaded in ZIP/PDF formats.

Subcontractor registrations and vendor credentials are systematically reviewed by our procurement division. The standard turnaround time is 7-10 working days, upon which a empanelment ID is assigned.
