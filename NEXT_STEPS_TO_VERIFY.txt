═══════════════════════════════════════════════════════════════════════════
                         IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════

Problem: Server won't start / Connection refused

Solution:
   1. Check if port 3001 is already in use
   2. Kill any existing node processes
   3. Try: npm start again
   4. If still fails, try: npm install && npm start


Problem: "SMTP Auth Error" in console

Solution:
   1. Check server/.env file exists
   2. Verify SMTP_USER and SMTP_PASS are correct
   3. Verify EMAIL_USER and EMAIL_PASS are correct
   4. If using Gmail, use App Password (not main password)
   5. Get new app password: https://myaccount.google.com/apppasswords


Problem: Form submits but no email received

Solution:
   1. Check browser console for errors (F12)
   2. Check server console for error messages
   3. Verify RECIPIENT_EMAIL in .env is correct
   4. Verify email wasn't marked as spam
   5. Check mailbox at aaraainfrastructure@gmail.com


Problem: Form shows old error message "Submission failed..."

Solution:
   1. Hard refresh page: Ctrl+Shift+R (not just F5)
   2. Clear browser cache
   3. Make sure you're on correct URL (localhost or your domain)
   4. Make sure backend is running (npm start)


Problem: Still seeing error after restarting server

Solution:
   1. Check that .env file was saved (open it and verify)
   2. Check that server/.env has all these variables:
      - SMTP_USER
      - SMTP_PASS
      - EMAIL_USER
      - EMAIL_PASS
      - RECIPIENT_EMAIL
      - PORT=3001
   3. Restart server again
   4. Hard refresh browser
